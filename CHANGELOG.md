## [1.0.0] - 2026-09-12

### Added

* Interactive particle-based 404 error page.
* Canvas-powered particle animation that forms the `404` message.
* Particle disintegration and reassembly effects.
* Interactive cursor and touch-based particle movement.
* **Reassemble** button to restore the particle formation.
* Responsive layout for desktop and mobile devices.
* Keyboard support with `Escape` triggering the reassembly action.
* Custom error message and navigation controls.
* Dark interface with glowing particle visuals.
* No external frameworks or dependencies.
* Pure HTML, CSS, and vanilla JavaScript implementation.
* Inline version for single-file usage.
* Minified inline version for simplified deployment.
* Desktop and mobile preview assets.
* Initial documentation with GitHub Pages and custom hosting instructions.
