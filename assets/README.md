# Assets

Assets used by the 404 page, including previews, animations, images, and other supporting files.

## Structure

```text
assets/
└── previews/
    ├── featured-and-gallery.png
    ├── desktop.png
    ├── mobile.png
    ├── open-graph.png
    └── something-interactive.gif
```

## Files

| File                                 | Purpose                               |
| :----------------------------------- | :------------------------------------ |
| `previews/featured-and-gallery.png`  | Featured and gallery preview          |
| `previews/desktop.png`               | Desktop preview                       |
| `previews/mobile.png`                | Mobile preview                        |
| `previews/open-graph.png`            | Open Graph and social sharing preview |
| `previews/something-interactive.gif` | Interactive animation preview         |

Additional assets may be added to this directory when required by the page.
