# Inline

Single-file versions of the 404 page with all required HTML, CSS, and JavaScript contained in one file.

## Files

| File             | Purpose                                                          |
| :--------------- | :--------------------------------------------------------------- |
| `index.html`     | Unminified single-file version for customization and development |
| `index.min.html` | Minified single-file version for deployment                      |

Copy either file to your project or hosting root and rename it to `404.html`.

No external CSS, JavaScript, or additional page files are required.
